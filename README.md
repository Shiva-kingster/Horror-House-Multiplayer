# 👻 Horror House Multiplayer

A 4-player multiplayer horror survival game built with HTML, CSS, JavaScript, Node.js and Socket.IO.

## 🎮 Features

- 4 Player Multiplayer
- Ghost AI
- Voice Ready Lobby
- Flashlight System
- Room Code Join
- Inventory System
- Real-Time Synchronization
- Host Migration
- Reconnect Support
- Responsive UI

---

## 🚀 Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Socket.IO
- Railway (Server)
- Vercel / Netlify (Client)

## ▶️ Local Setup

Install dependencies

```bash
npm install
```

Run server

```bash
npm start
```

Open

```
http://localhost:3000
```

---

## 🌐 Deployment

### Client

Deploy **index.html** on:

- Vercel
- Netlify

### Server

Deploy:

- server.js
- package.json

on Railway.
